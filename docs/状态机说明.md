# 状态机说明（RP27_Dart V0.6）

> [!tip] 前置知识
> 先读 [遥控器手册](遥控器手册.md)，了解模式和拨轮操作。本文写的是遥控操作背后的完整规则，对应代码 `Application/ControlLayer/dart_fsm.c`、`fire_gate.c`。

> [!warning] 本文尚未上机验证
> 下面所有时序和阈值都是软件设计值，没有实机记录。

## 1. 模式

| 模式 | 进入方式 | 电机输出 |
|---|---|---|
| SAFE | S1 下；遥控离线或数据异常；上电或重连后还没见过 S1 下位 | Yaw、变力停止；上膛按第 5 节受控回退后停止 |
| MANUAL | S1 上 | 允许，单机构调试 |
| SEMI_AUTO | S1 中 | 允许，遥控触发单发流程 |
| AUTO | 预留，等裁判协议到手后实现 | — |

- **上电或遥控重新上线后，S1 必须先拨到下位一次**，否则一直停在 SAFE。
- **自动找零**（`DART_AUTO_ZERO_ENABLE=1`）：
  - 上电后**第一次把 S1 拨离安全位**时，对还没找零的轴自动堵转找零，每次上电只做一次。
  - 电机离线导致零点丢失后不会自动重找，需要人工找零。
  - 可以用手动模式 S2 上位的拨轮下拨取消，也可以拨回安全位取消。
- 人工零点函数 `Mech_Axis_Set_Zero_Here` 保留在代码里，但目前没有映射到遥控，三轴都用堵转找零。

## 2. 储能状态 energy

energy 是软件推定值，不是传感器读数。

| 规则 | 内容 |
|---|---|
| 上电 | UNKNOWN。单发启动前，必须先在 MANUAL 模式下执行一次人工卸力（找零后，3 s 内拨轮上拨两次） |
| 置为 UNKNOWN | 以下操作无法证明机构未储能：人工锁止撒放器；撒放器未释放时点动上膛；在 LOCK 步骤中止 |
| 自动推定为 RELEASED | 撒放器已打开，且上膛在 UP。此时滑台不可能储能 |
| UNKNOWN 或 STORED 时 | 不能启动新一发，也不能直接打开撒放器；只能恢复原流程，或执行人工卸力 |

## 3. 单发流程

| 步骤 | 进入时动作 | 完成依据 | 下一步 |
|---|---|---|---|
| IDLE | — | 拨轮上拨，并通过启动检查 | LOAD_PREP |
| LOAD_PREP | 撒放器释放，上膛回 UP | 撒放器已释放，且上膛在 UP 到位稳定 | LOAD_MID（若 `FEED_BEFORE_LOAD=1`，先到 FEED_EARLY） |
| LOAD_MID | 上膛快速移到 MID | 到位稳定 | LOAD_DOWN |
| LOAD_DOWN | 上膛慢速移到 DOWN | 到位稳定 | LOCK |
| LOCK | 撒放器锁止 | 等待 300 ms，energy 标记为 STORED | LOAD_RETURN |
| LOAD_RETURN | 上膛回 UP | 到位稳定 | FEED |
| FEED | 执行当前发序的供弹步骤表（第 1 发为 0 步） | 步骤表执行完 | AIM_TENSION |
| AIM_TENSION | Yaw 和变力转到当前发序的预设 | 两者都到位稳定，且力就绪（目前是桩） | ARMED |
| ARMED | — | 再次拨轮上拨，并通过 `Fire_Gate_Check` | FIRING（被拒时留在 ARMED，并记录原因） |
| FIRING | 撒放器释放，发数 +1 | 撒放器已释放，且已等待 800 ms | RESET |
| RESET | 撒放器锁止 | 撒放器已锁止，发序 +1 | IDLE |

**启动检查**（全部满足才能启动）：
- 三轴都已找零；
- energy 不是 UNKNOWN，也不是 STORED；
- 发序 ≤4；
- 无故障，电机全部在线，供弹不在执行中；
- 本发需要供弹时，`DART_FEEDER_CALIBRATED` 必须为 1。未标定时只能打不需要供弹的第 1 发，供弹只能在 MANUAL 中单测。

**释放许可**：每次释放都重新检查以下各项，拒绝原因见 `fire_gate.h` 的 `fire_deny_e`。
- 检查项：模式、遥控、故障、电机、找零、撒放器锁止、上膛在 UP、Yaw 就绪、变力和力就绪、供弹空闲、裁判许可、双控件确认。
- **保持带**：Yaw、变力、上膛三项只要求"曾经到位，并且当前仍在一个比到位判定更宽的范围内"（`*_FIRE_HOLD_ERR/SPEED`，约为到位带的 3 倍），避免镖架轻微抖动导致误拒。AIM_TENSION 步骤仍用严格的到位判断，其余硬条件不放宽。
- 被拒后不会自动重试，需要重新拨一次；被拒时蜂鸣器给出 DENY 提示音。
- **防呆**：默认 `DART_FOOLPROOF_TWO_STEP`。改成 `DUAL_INPUT` 后，ARMED 状态下释放还需要右竖摇杆推满（≥600）。

**中止与恢复**
- 以下情况都会中止流程，进入 ABORTED：拨轮下拨、离开 SEMI_AUTO、关控、轴故障、步骤兜底超时（10 s）。
- 中止后三轴原地保持，撒放器不动作。
- 恢复需要再次上拨。各状态的恢复入口：ARMED 恢复到 AIM_TENSION 重新确认；FIRING 恢复到 RESET；其余从中止时所在的步骤重新开始。
- 在 MANUAL 模式下做任何操作，都会丢弃这次中止的现场。丢弃现场不会把储能状态改成"已释放"。
- 在供弹步骤中止后，**不会重做供弹序列**（可能重复放镖）：S2 上位恢复会被拒绝；人工确认储弹后，S2 下位上拨，跳过供弹继续。

## 4. 人工卸力流程（2a 反向接力）

| 步骤 | 动作 | 完成条件 |
|---|---|---|
| UNLOAD_TENSION | 仅当 `UNLOAD_REDUCE_TENSION=1` 时执行：变力到 `TENSION_POS_UNLOAD` | 变力就绪 |
| UNLOAD_CATCH | 上膛快速到 MID（接触点之前） | 到 MID 稳定 |
| UNLOAD_CATCH_SLOW | 上膛慢速到 `LOADER_POS_CATCH`，重新顶住已锁止的滑台 | 到接住位稳定 |
| UNLOAD_OPEN | 撒放器释放，拉簧力由电机承担 | 已释放，并再等 `UNLOAD_OPEN_HOLD_MS` |
| UNLOAD_RETURN | 上膛以 `LOADER_SPEED_RETREAT` 送回 UP | 到 UP 稳定，储能状态改为 RELEASED |

- 前置条件：上膛已找零，L/R 两台电机在线，上膛无故障。不满足就拒绝，原因记入 `last_unload_deny`。
- 每一步有 10 s 超时。拨轮下拨或离开 MANUAL 都会中止卸力，上膛原地保持。
- 到达 `LOADER_POS_CATCH` 只说明编码器到位，**不能证明拨弹板已经接住拉簧力**。需要机械确认，首次测试不装镖。

**打开撒放器瞬间的电流冲击**（UNLOAD_OPEN，用户 2026-11-04 判断可以接住，冲击大小待实测）

撒放器一打开，拉簧力从锁扣瞬间转到拨弹板上，位置误差突然增大，速度环输出会迅速升高。上限是 `DART_3508_OUT_MAX` = 16000 raw，按 C620 的 16384 ≈ 20 A 换算，约 19.5 A。短时间达到这个值，一般不会损坏 3508 或电调，需要关注的是另外几件事：

| 关注点 | 可能现象 | 首次测试时怎么看 |
|---|---|---|
| 同步带跳齿或打滑 | `pos` 突然回退一大段且回不来；零点作废 | 记录 `s_loader_axis.pos`，看开锁前后的回退量 |
| 误报保持卡死 | 回退超过 `LOADER_HOLD_STALL_ERR` 并满足堵转条件，轴进入故障；上膛 `hold_on_fault` 会继续保持 | 看 `s_loader_axis.status` / `err` 是否变为故障 |
| 电流打满 | 输出长时间贴在 16000，说明电机顶不住 | 记录 `s_rx[0/1].torque_current_raw`（L/R）峰值和持续时间 |
| 机械冲击 | 结构撞击声、拨弹板变形 | 人工观察 |

减小冲击的方向（实测后再决定，当前代码没有实现）：
- 让 `LOADER_POS_CATCH` 比 DOWN 略深，开锁前拨弹板已经预先承担一部分力，锁扣卸载后再打开。
- 在 UNLOAD_OPEN 期间临时加大位置环刚度，或者限制开锁后的回退速度。

测试步骤：不装镖，对着缓冲，用 MemRW3 同时记录 `pos` 和 L/R 两路 `torque_current_raw`，把峰值记进 [CHANGELOG](../CHANGELOG.md)。

## 5. 安全行为

| 场景 | 行为 |
|---|---|
| SAFE 模式或遥控离线 | 舵机保持当前脉宽；Yaw、变力立即停止输出；上膛按下一行处理 |
| **受控回退**（停止类别 1） | 进入 SAFE 时，如果上膛已找零、无故障、在线、不在 UP，且撒放器未锁止（滑台只靠电机拉着），上膛先以 `LOADER_SPEED_RETREAT` 送回 UP，再清零输出。回退超时由轴按距离自动计算（理论时间 × 1.5 + 1 s），超时会记故障并停止。回退之后，中止现场的恢复入口改为 LOAD_MID |
| 上膛单侧离线（策略 A） | 只有 R 离线时，L 单独原地保持（零点仍有效），状态机中止流程。拨回 SAFE 时立即以 `LOADER_SPEED_RETREAT_SINGLE` 单侧回退；其他模式下，保持超过 `LOADER_SINGLE_HOLD_MAX_MS` 也会自动回退。L 离线时 L 是位置来源，无法闭环，两侧都停止输出 |
| 运动超时 | 所有轴都按"距离 ÷ 限速 × 1.5 + 1 s"计算超时，配置里的 `*_MOVE_TIMEOUT_MS` 只是下限 |
| 保持卡死 | 点动或保持时，目标与实际位置相差超过 `*_HOLD_STALL_ERR`，且满足堵转条件，判为堵转故障；点动目标最多超前 `*_JOG_LEAD_MAX` |
| 离线故障优先 | 离线可以覆盖已有的其他故障，确保停止输出 |
| 撒放器已锁止时进入 SAFE | 锁扣是机械自锁，电机直接清零，是安全的 |
| 轴运动超时或堵转 | 上膛保持当前位置（`hold_on_fault`），变力和 Yaw 停止输出。拨回 SAFE 才能确认并清除这类故障 |
| 电机离线 | 对应轴的零点作废，必须重新找零 |

> [!warning]
> 上膛故障、离线或未找零时无法回退，滑台会回弹，只能靠机械缓冲。

## 6. 提示音与指示灯

操作手看到的含义见 [遥控器手册](遥控器手册.md) 第一章第 5 节。触发条件如下：

| 提示音 | 声音 | 触发条件 |
|---|---|---|
| ZERO_DONE | 短响 1 声 | 三轴全部找零完成 |
| ARMED | 短响 2 声 | 进入待发 |
| DENY | 一长一短 | 启动、恢复、释放、卸力被拒 |
| FAULT | 短响 3 声 | 出现新故障 |

`buzzer.c` 非阻塞，高优先级提示音可以打断低优先级。

指示灯：蓝灯表示遥控在线；绿灯表示电机全部在线，找零时闪烁；红灯常亮表示有故障，快闪表示 ARMED 或已储能，慢闪表示 ABORTED。
