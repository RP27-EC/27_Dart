# 上机调试流程：镖架造好后，从第一次上电到能稳定发射

> [!tip] 前置知识
> - 会用 Keil 编译烧录，会用 MemRW3 或 Ozone 读写变量，见 [调试与调参](调试与调参.md)。
> - 已经读过 [遥控器手册](遥控器手册.md)：S1 下 = 安全，S1 上 = 手动，S1 中 = 半自动。
> - 本文是总流程，每一步的细节都链接到对应文档：[PID 调试指南](PID调试指南.md)、[标定与测量](标定与测量.md)、[状态机说明](状态机说明.md)。

> [!warning] 本流程本身也没有上机验证过
> 本文根据当前固件（V0.6）的代码逻辑编写。第一次照着做时，遇到和文中描述不一致的地方，以实物现象为准，并把差异记进 [CHANGELOG](../CHANGELOG.md)，再回来修改本文。

## 总览

| 阶段 | 步骤 | 做完后得到什么 |
|---|---|---|
| A 准备 | 0 安全准备 → 1 上电前检查 → 2 首调固件配置 | 一份"低输出、不自动动作"的固件 |
| B 通信 | 3 首次上电 → 4 遥控核对 | 电机在线，遥控方向确认 |
| C 方向与零点 | 5 电机方向 → 6 上膛双电机镜像 → 7 找零方向与堵转 | 三轴能正确找零 |
| D 闭环 | 8 速度环 PID → 9 位置环 PID | 三轴走位置又快又稳 |
| E 行程 | 10 行程与软限位 → 11 回转位与中位 | 正式的位置参数 |
| F 执行器 | 12 撒放器舵机 → 13 供弹舵机（到货后） | 舵机脉宽 |
| G 恢复正式输出 | 14 恢复输出上限并复核 | 正式限幅下动作正常 |
| H 流程 | 15 卸力 → 16 单发空跑 → 17 带镖单发 → 18 异常测试 | 单发流程可信 |
| I 打靶 | 19 每发参数标定 → 20 四发连续 | 打靶参数 |
| J 收尾 | 21 定版与归档 | 可追溯的版本 |

**基本原则**
- **顺序不能乱**：方向没确认就不能找零，没找零就不能调 PID（调参接口要求已找零），PID 没调好就测不准行程。
- **每一步都要记录**：日期、固件版本（AXF 的编译时间）、改了哪些宏、改之前和改之后的值、现象。记进 [CHANGELOG](../CHANGELOG.md)。
- **一次只改一个量**：改完一个参数就验证一次，不要一次改一堆再看结果。
- **调好的值只在 RAM 里**：用调试器改的参数掉电就恢复原值，必须写回 `dart_config.h`、重新编译，才算真正保存。

## 阶段 A：准备

### 步骤 0：安全准备

**目的**：保证出现任何意外动作时，人不受伤、机构不损坏。

**操作**
1. 电池和电源之间接一个**伸手可及的总开关**（或者急停），所有调试过程中都由一名专人负责。
2. 镖架前方放好**缓冲或接镖网**，射线方向清场。
3. 前 15 步**全部不装镖**。
4. 准备好：遥控器（已与接收机对频）、J-Link、装好 Keil 和 MemRW3 的电脑、卷尺和角度尺，以及一份打印好的记录表（[标定与测量](标定与测量.md) 第 5 节）。
5. 至少两人在场：一人操作遥控和电源，一人看电脑数据。

**注意**
- **遥控关机就是"停止"**：遥控离线后进入 SAFE，电机输出清零。但这不等于已经卸能。下拉途中断电或关控，滑台可能回弹，见 [状态机说明](状态机说明.md) 第 5 节。
- 调试时**不要在 MemRW3/Ozone 里暂停 CPU**。CPU 暂停后控制循环停止，电调的行为待确认。

### 步骤 1：上电前检查（不上电）

**目的**：在通电前排除接线和装配错误。

**操作**

| 检查项 | 方法 | 合格标准 |
|---|---|---|
| CAN1 接线 | 对照 [README](../Readme.md) 资源表 | 上膛 L、上膛 R、变力三台 C620 接 CAN1 |
| Yaw 接线 | 同上 | 当前代码中 Yaw 的 C610 接 **CAN2**。如果决定改回 CAN1，要先改代码 |
| 电调 ID | 按 C620/C610 说明书设置 | 上膛 L = 1，上膛 R = 2，变力 = 3，Yaw = 4。同一路 CAN 上不能重复 |
| CAN 终端电阻 | 万用表断电测 CAN_H–CAN_L | 每一路约 60 Ω（两端各 120 Ω） |
| 舵机供电 | 万用表测舵机电源电压 | 符合所选舵机的额定电压，不能直接接电池电压 |
| 舵机信号线 | 对照资源表 | PE9 撒放器，PE11 剪叉 A，PE13 剪叉 B，PE14 储弹限位 |
| **舵机摇臂** | — | **第一次上电时，舵机摇臂先不要连到连杆或锁扣上**（原因见步骤 2） |
| 机构手动转动 | 断电时用手推动三根轴 | 全行程无卡滞；记下机械限位大概在哪一端 |
| 撒放器状态 | 目视 | 滑台没有被锁住，拉簧处于放松状态 |

**注意**
- 舵机上电后会立刻转到固件里设定的初始脉宽：撒放器 500 µs，供弹舵机 1500 µs。这些是 26 的值或占位值，新舵机和连杆上的位置是未知的。**摇臂接着连杆时，上电瞬间可能顶死或拉坏机构。**

### 步骤 2：首调固件配置

**目的**：做一份"出力小、不会自己动"的固件。即使方向或参数错了，后果也有限。

**操作**：在 `Application/ConfigLayer/dart_config.h` 中临时修改以下宏（每改一项都记下原值）：

| 宏 | 首调值 | 原值 | 原因 |
|---|---|---|---|
| `DART_TEST_MODE` | 1（保持） | 1 | 调参接口 `g_dart_tune` 只在测试模式下编译 |
| `DART_AUTO_ZERO_ENABLE` | **0** | 1 | 方向确认之前，禁止上电后自动找零 |
| `DART_3508_OUT_MAX` | **3000.0f** | 16000.0f | 上膛和变力出力小，方向错了也顶不坏 |
| `DART_2006_OUT_MAX` | **2000.0f** | 9000.0f | Yaw 同理 |
| `DART_FEEDER_CALIBRATED` | 0（保持） | 0 | 供弹未标定，禁止自动供弹 |

然后用 Keil 编译（日志末尾为 `0 Error(s)`），并烧录。

**注意**
- 这些首调值只是建议。3000 raw ≈ 3.7 A，足够让空载机构动起来；如果连空载都推不动，再逐步往上加。
- `*_ZERO_OUT_MAX`（找零电流上限）会被 `DART_*_OUT_MAX` 再限一次，所以首调期间找零也是低出力。
- 这份固件**不能用于正式发射**。步骤 14 要把它们改回去。

## 阶段 B：通信

### 步骤 3：首次上电

**目的**：确认主控、电调、CAN 通信都正常。

**操作**
1. S1 拨到**下位**，打开遥控。
2. 合上总开关，给镖架上电。观察是否有冒烟、异味或异常发热，有就立即断电。
3. 看 C 板指示灯：
   - 蓝灯亮：遥控在线；
   - 绿灯亮：四台电机全部在线；
   - 红灯：上电初期可能有离线故障，电机全部在线后会熄灭。拨一次 S1 下位确认清除。
4. 用 MemRW3 以 **Attach** 方式连接（不要下载，不要复位），加载 `My_C.axf`，添加以下变量：
   - `s_fsm.mode`：应为 0（安全）；
   - `s_fault_mask`：应为 0；
   - `g_dart_motor[0..3]` 的 `state` 和 `rx_info`：四台电机在线时，`encoder` 是一个 0～8191 之间的值。

**完成标准**：绿灯常亮，`s_fault_mask = 0`，四台电机的编码器都有读数。

**常见问题**

| 现象 | 可能原因 |
|---|---|
| 绿灯不亮 | 某台电机离线：查电调 ID、CAN 线、电调供电。Yaw 要接在 CAN2 上 |
| `s_fault_mask` 的 bit1～bit4 为 1 | 对应电机离线（位定义见 [调试与调参](调试与调参.md) 第 3 节） |
| 蓝灯不亮 | 接收机没对频，或 DBUS 线没接好 |

### 步骤 4：遥控核对

**目的**：确认拨杆、拨轮、摇杆的方向和代码里的约定一致。方向弄反了，后面所有操作都会错。

**操作**：在 MemRW3 中添加 `s_rc_cmd`（rc_cmd.c 中的遥控快照），以及 `rc_sensor_info` 的 `s1`、`s2`、`thumbwheel`、`ch0～ch3`。

| 动作 | 预期 | 不符合时 |
|---|---|---|
| S1 拨到上、中、下 | `s_rc_cmd.s1` 依次为 1（上）、2（中）、3（下） | 物理左右拨杆与代码相反：交换遥控上的使用约定，并更新遥控器手册 |
| S2 同上 | `s_rc_cmd.s2` 同上规律 | 同上 |
| 拨轮**往上**拨到底再松开 | `s_rc_cmd.wheel_evt` 出现一次 1（上拨）。这个事件只持续一个周期，可能看不到，可以改看 `thumbwheel.value` 是否为负 | 改 `RC_WHEEL_UP_SIGN` 的符号 |
| 右摇杆向上推 | `s_rc_cmd.ch1` 为正 | 记录下来。点动方向会跟着反过来，在步骤 5 里统一处理 |
| 右摇杆向右、左摇杆向上 | `ch0` 为正，`ch3` 为正 | 同上 |
| 遥控关机 | `s_rc_cmd.online` 变为 0，蓝灯灭，`s_fsm.mode = 0` | 检查接收机失控保护设置 |
| 遥控重新开机，S1 不在下位 | 仍停在安全模式（`safe_seen = 0`）；S1 拨到下位一次后才能进入其他模式 | 这是设计行为 |

**完成标准**：上表每一行都符合预期，或者已经改好宏并重新烧录。

## 阶段 C：方向与零点

### 步骤 5：电机方向（逐轴）

**目的**：确定每根轴的"逻辑正方向"。约定是：**逻辑位置 `pos` 增大 = 远离找零所顶的那个限位**。

- 上膛：远离 UP 侧的限位，也就是往下拉。
- 变力：远离零点限位。
- Yaw：从 0° 一侧转向 18° 一侧。

**为什么要先做**：找零时电机朝"逻辑负方向"顶限位。如果方向反了，电机会朝另一端撞过去，或者撞向不允许撞的地方。

**操作**（每次只做一根轴，建议顺序：Yaw → 变力 → 上膛）
1. 用手把机构推到行程中间附近，远离两端限位。
2. S1 拨到**上位**（手动）。因为步骤 2 已关闭自动找零，此时不会有动作。
3. 在 MemRW3 中观察对应轴对象的 `pos`、`speed`、`output`、`status`：`s_yaw_axis`（yaw.c）、`s_tension_axis`（tension.c）、`s_loader_axis`（loader.c）。
4. 用摇杆**轻推一点**做点动：
   - Yaw：S2 中位，右摇杆左右；
   - 变力：S2 中位，左摇杆上下；
   - 上膛：**先跳过，放到步骤 6 再做**。
5. 观察两件事：
   - **物理方向**：机构往哪边动了？
   - **`pos` 的变化**：是增大还是减小？
6. 判断：
   - 摇杆推正、`pos` 增大，且机构**远离**找零限位 → 方向正确。
   - `pos` 增大，但机构**朝向**找零限位 → 把对应的 `*_DIR_SIGN` 取反（1 ↔ -1）。
   - 点动时机构不动但 `output` 很大 → 出力不够，或者机构卡住，先排查机械问题。
7. 改完宏后重新编译、烧录，再验证一遍。

**完成标准**：Yaw 和变力两根轴都满足"摇杆正推 → `pos` 增大 → 远离找零限位"。

**注意**
- **未找零时点动不受软限位约束**，只靠点动超前限制（`*_JOG_LEAD_MAX`）和低输出上限保护。推摇杆要轻、时间要短，眼睛盯着机构，接近端部就松手。
- 如果摇杆方向本身是反的（步骤 4 的记录），只影响操作手感，不影响 `DIR_SIGN` 的判断。判断只看 **`pos` 的变化方向和物理运动方向**。
- `DIR_SIGN` 一变，所有位置参数的正负含义都跟着变。这一步必须在测量任何位置之前完成。
- Yaw 的 `YAW_DIR_SIGN` 当前为 -1，是按"物理找零方向与 26 一致"设定的。新平 Yaw 是否仍然如此，就在这一步确认。

### 步骤 6：上膛双电机镜像与方向

**目的**：确认上膛两台 3508 出力方向一致（R 的输出 = `LOADER_R_MIRROR_SIGN` × L 的输出），并确定上膛的 `LOADER_DIR_SIGN`。

**为什么要单独做**：镜像符号错了，两台电机会互相顶着用力，同步带受力最大，机构却几乎不动。

**操作**
1. 确认撒放器**没有锁住**滑台。
2. 在 MemRW3 中添加：`s_loader_axis` 的 `pos`、`output`，以及 `s_rx[0]`、`s_rx[1]`（dart_motor.c，分别是 L 和 R）的 `encoder_speed` 和 `torque_current_raw`。
3. 手动模式 S2 上位，右摇杆**轻推一下**。
4. 判断镜像：

| 现象 | 结论 |
|---|---|
| 机构顺畅移动；L、R 的 `torque_current_raw` 符号相反，大小相近 | 镜像正确（两台电机镜像安装时） |
| 机构几乎不动，L、R 电流都很大 | **镜像符号错了，两台电机在互相顶。** 立即松手，把 `LOADER_R_MIRROR_SIGN` 取反 |
| 只有一台电机有电流 | 另一台离线，或电调输出异常 |

5. 镜像确认后，按步骤 5 的方法确定 `LOADER_DIR_SIGN`：`pos` 增大 = 往下拉，远离 UP 侧限位。

**注意**
- 上膛往下拉的过程中，一旦拨弹板碰到滑台，**拉簧就开始储能**。这一步只在接触点之前的空行程里小范围移动。
- 撒放器未释放时点动上膛，储能状态会被置为"未知"，这是正常的保护。

### 步骤 7：找零方向与堵转参数

**目的**：让三轴都能可靠地堵转找零：顶到限位后能判定为堵转，而运动途中不会误判。

**操作**（先单轴，再三轴同时；建议顺序：Yaw → 变力 → 上膛）
1. 把机构手动推到离找零限位**不远**的位置（例如行程的 1/4 处），这样即使出问题，撞击速度也不会太大。
2. MemRW3 中观察：对应轴的 `status`（1 = 找零中）、`speed`、`output`、`err`、`zeroed`。
3. 手动模式 S2 上位，拨轮**下拨**：三轴同时开始找零。
   - 只想测一根轴时，可以先把另外两根轴手动推到限位附近，或者准备好在它们开始动时再拨一次拨轮取消。
   - **找零过程中再拨一次拨轮，就是取消**，三轴原地保持。
4. 观察找零过程：
   - 电机应朝**找零限位**方向运动，速度大致稳定；
   - 顶到限位后约 100 ms，`zeroed` 变为 1，然后自动回转到回转位（`status` 先变为 3 运动中，再变为 4 到位）；
   - 三轴全部完成后，蜂鸣器响 1 声。
5. 记录顶住限位时 `output` 的稳定值（堵转电流）和 `speed`（应接近 0）。

| 现象 | 处理 |
|---|---|
| 朝反方向跑 | 立即取消。回到步骤 5 检查 `DIR_SIGN`；如果 `DIR_SIGN` 确认无误，就是 `*_ZERO_SPEED` 的符号错了 |
| 顶住了但一直不判堵转，最后找零超时（`err` = 1） | 堵转时的 `output` 达不到 `*_STALL_OUT_MIN`：首调输出上限太低，或者阈值太高。在不超过机构承受力的前提下，适当调整 |
| 还没到限位就判了堵转 | 运动阻力大，`output` 已超过阈值且速度低：提高 `*_STALL_OUT_MIN`，或者降低 `*_STALL_SPEED_MAX` |
| 回转时报运动超时 | 回转位太远或限速太低，在步骤 11 里调整 |

6. 三轴都能单独正常找零后，把 `DART_AUTO_ZERO_ENABLE` 改回 **1**，重新烧录，验证"上电后第一次拨离安全位就自动找零"。

**完成标准**：三轴连续找零 3 次都成功；每次的零点一致（找零后读 `pos` 偏差很小）；记录了每轴的堵转电流。

**注意**
- 变力和 Yaw 按 26 的做法保留堵转找零。机械曾提醒非拨弹板传动尽量不要撞限位：找零速度不要提高，第一次找零时听声音、看结构有没有变形。
- 找零阈值的当前值来自 26（变力 2000/10，Yaw 1000/50，上膛 1000/10），**新机构上必须重新确认**。

## 阶段 D：闭环

详细方法见 [PID 调试指南](PID调试指南.md)。这里只列执行顺序和完成标准。

### 步骤 8：速度环（内环）PID

**目的**：让电机转速快速、准确地跟随目标转速。内环不稳，外环无论怎么调都不会好。

**操作**（每根轴分别做）
1. 确认该轴已找零，机构停在行程中间附近。
2. 加载对应轴的 MemRW3 配置：Yaw 用 `memrw3_config.json`，变力用 `MemRW3_变力调参.json`，上膛用 `MemRW3_上膛调参.json`。加载后要**手动写 `g_dart_tune.axis`**（0 上膛、1 变力、2 Yaw），配置不会自动写入。
3. 依次写入 `g_dart_tune.mode = 1`（速度）、`speed_rpm` = 一个小值（例如 300），最后写 `enable = 1`。
4. 看 `active` 是否为 1。如果是 0，就看 `deny` 的拒绝原因：1 不在手动，2 轴非法，4 未找零，8 可能储能，16 轴拒绝。
5. 用 `speed_rpm` 做正负阶跃，观察目标转速和实际转速两条曲线，调该轴的 `spd_pid.kp`、`ki`。
6. 到达软限位时，轴会自动保持。注意来回切换方向，不要一直朝一个方向跑。
7. 退出：`enable` 写 0，或者拨轮下拨。

**完成标准**（建议值，可按机构调整）：阶跃响应没有持续振荡，超调小，稳态误差接近 0；加上负载后（例如上膛顶住滑台时）不发散。

**注意**
- 调上膛时，储能状态必须是"已释放"，且不能在卸力过程中（否则 `deny` = 8）。
- 首调期间输出上限较低，`output` 可能顶到上限。这时响应偏慢是限幅造成的，不是 PID 的问题，不要为此加大增益。步骤 14 恢复正式上限后还要再验证一次。

### 步骤 9：位置环（外环）PID

**目的**：让轴准确走到目标位置、停稳，并且满足到位判定（误差和速度都在阈值内，并持续一段时间）。

**操作**
1. `g_dart_tune.mode = 2`（位置），写好 `pos_target` 和 `pos_speed_limit`，`enable = 1`。
2. 每改一次 `seq`（例如 0 改成 1），发起一次运动。
3. 用小步、大步分别测试，观察 `target`、`pos` 两条曲线和 `status`：应变为 3 运动中，然后变为 4 到位。
4. 调该轴的 `pos_pid.kp`（`ki` 一般保持 0）。

**完成标准**：
- 不同步长都能到位（`status` = 4），没有来回振荡；
- 到位后停稳，没有爬行；
- 到位时间大致满足节拍要求（30 s 四发要留出余量）。

**注意**
- `out_max` 等运行字段会被固件重写，不能当作持久参数来调。
- 调好的 `kp/ki/kd` 要写回 `dart_config.h` 的 `*_POS_KP`、`*_SPD_KP/KI/IMAX`，重新编译。

## 阶段 E：行程

详细方法和记录表见 [标定与测量](标定与测量.md)。

### 步骤 10：行程与软限位

**目的**：测出每根轴的实际可用行程和关键点位，写成正式的位置参数和软限位。

**操作**
1. 撒放器打开，不装镖，对着缓冲。
2. 在 RAM 中临时放宽要测的轴的 `pos_max`（以及 Yaw 的 `pos_min`），见标定与测量第 3.1 节。
3. 用 `g_dart_tune` 位置模式**低速、小步**移动，依次记录各点：
   - 上膛：UP → 接触点 → MID → DOWN → CATCH → 机械极限；
   - 变力：回转位 → 最小预紧 → 最大预紧；
   - Yaw：中位 → 左右极限；再走一段已知的 8192 count，用角度尺量出实际角度，算出 `YAW_COUNT_PER_DEG`。
4. 把结果写回 `dart_config.h`，并检查大小关系：0 < UP < MID < 接触点 ≤ DOWN ≤ CATCH < POS_MAX。
5. 重新编译、烧录，**断电重启**，确认软限位恢复为新的配置值。

**完成标准**：记录表填完；新参数烧录后，三轴在软限位内都能正常走到各个点。

**注意**
- **测上膛 DOWN 时，锁扣可能扣上，滑台就处于储能状态。** 此时不要直接打开撒放器，要执行步骤 15 的卸力流程。步骤 15 还没验证的话，就请机械协助手动卸力。
- 放宽软限位期间没有软件保护，接近端点时把步长减到 2000 count 以下。
- 变力的"最小预紧位置"要实机测量。测出来之前，`UNLOAD_REDUCE_TENSION` 保持 0。

### 步骤 11：回转位与中位

**目的**：确定找零后停在哪里：上膛的 UP 位、变力的回转量、Yaw 的中位。

**操作**：见标定与测量第 2.4、2.5 节。先在 RAM 里改 `home_pos`，验证没问题后再写回 `LOADER_POS_UP`、`TENSION_ZERO_BACKOFF`、`YAW_DEG_CENTER`。

**完成标准**：每次找零后都停在同一个位置，离开限位，并留有余量。

**注意**：`LOADER_POS_UP` 同时被单发流程使用。改了它之后，要确认撒放器锁止时拨弹板不碰滑台，并复核 `LOADER_FIRE_HOLD_ERR`。

## 阶段 F：执行器

### 步骤 12：撒放器舵机

**目的**：找到撒放器"锁止"和"释放"两个位置的脉宽，以及动作所需时间。

**操作**
1. **摇臂仍不连接锁扣。** 在 MemRW3 中添加 `s_servo[0].pulse_now`（servo.c，0 号为撒放器）。
2. 固件每 1 ms 会把 `pulse_now` 写到 PWM。直接在调试器里改写它，舵机就会转到对应位置。从 1500 开始，每次改 50～100 µs，找到锁止位和释放位。
3. 断电，按锁止位装好摇臂、连上锁扣。上电后，在**没有拉簧力**的情况下用调试器切换两个脉宽，确认锁扣能可靠扣上和打开。
4. 用秒表或慢动作视频估计动作时间，作为 `TRIGGER_SETTLE_MS` 的依据（当前为 300 ms）。
5. 写回 `TRIGGER_PULSE_LOCK`、`TRIGGER_PULSE_RELEASE`、`TRIGGER_SETTLE_MS`，重新编译。

**完成标准**：用遥控（手动模式 S2 上位，拨轮上拨）切换撒放器时，锁止和释放都动作到位、没有卡顿；舵机静止时没有持续的嗡嗡声（嗡嗡声说明顶死了）。

**注意**
- 用调试器改 `pulse_now` 只是标定手段。撒放器状态机收到新请求时会覆盖它，而且状态机并不知道你改过这个值。
- 舵机没有位置反馈，固件里的"已锁止/已释放"只是按时间推定的。

### 步骤 13：供弹舵机（舵机到货后）

**目的**：标定三只供弹舵机的脉宽和每步的保持时间，让供弹序列能稳定地一次放下一枚镖。

**动作顺序**（用户 2026-11-04 描述）：限位舵机放行 → 镖靠重力落到剪叉上 → 限位舵机挡住 → 两个剪叉舵机把镖放下 → 剪叉回到接镖位。

**操作**
1. 和步骤 12 一样，先不连连杆。用 `s_servo[1]`（剪叉 A）、`s_servo[2]`（剪叉 B）、`s_servo[3]`（储弹限位）的 `pulse_now`，分别找出：
   - 剪叉 A/B 的**接镖位**和**放镖位**。两只剪叉通常是对称安装，脉宽可能是镜像关系，要分别确认；
   - 限位舵机的**挡住**位和**放行**位。
2. 装好连杆，在没有镖的情况下，用手动模式 S2 中位的拨轮**上拨**（单独执行当前发序的供弹）走一遍整套序列，观察动作和时序。
3. 装一枚镖测试，重点确认：**每次只放下一枚**，镖落到导轨上的姿态正确，剪叉回位时不碰镖。
4. 调整 `FEEDER_STEP_HOLD_MS`；如果每一步需要的时间不同，就要修改 `feeder.c` 里的步骤表。
5. 写回 `FEEDER_LIFT_A/B_PULSE_HOME/DOWN`、`FEEDER_STOP_PULSE_LOCK/OPEN`，并把 **`DART_FEEDER_CALIBRATED` 改为 1**，重新编译。
6. 手动模式 S2 下位，拨轮上拨，确认"供弹舵机全部回初始位"能正常工作。

**完成标准**：连续供弹 10 次以上，每次只落一枚，姿态正确。

**注意**
- 没有有镖、缺镖、卡镖传感器。序列"执行完"不代表镖真的到位了，每次测试都要目视确认。
- `DART_FEEDER_CALIBRATED = 0` 时，半自动模式只能打第 1 发（第 1 发不需要供弹）。

## 阶段 G：恢复正式输出

### 步骤 14：恢复输出上限并复核

**目的**：把步骤 2 的临时配置改回正式值，并确认正式出力下各项依然正常。

**操作**
1. 在 `dart_config.h` 中，把 `DART_3508_OUT_MAX` 改回 16000.0f，`DART_2006_OUT_MAX` 改回 9000.0f。确认 `DART_AUTO_ZERO_ENABLE = 1`。
2. 编译、烧录。
3. 复核：
   - 三轴自动找零正常，且找零阈值没有因为输出变大而误判（步骤 7）；
   - 速度环和位置环的阶跃响应没有变差（步骤 8、9）。输出上限变大后，原先被限幅掩盖的超调可能会表现出来。

**完成标准**：步骤 7、8、9 的完成标准在正式输出上限下仍然满足。

## 阶段 H：流程

### 步骤 15：人工卸力流程

**目的**：确认"已经锁住、储能，但决定不打"时，能安全地把能量放掉。后续所有带储能的操作都依赖这个流程，所以要在单发之前先验证。

**操作**
1. 不装镖，对着缓冲。先人为制造一个储能状态：用步骤 16 的半自动流程走到锁止之后，再中止。或者请机械协助。
2. 在 MemRW3 中记录：`s_fsm.unload_step`、`s_loader_axis.pos`、`status`，以及 `s_rx[0/1].torque_current_raw`（L/R 电流）。
3. 手动模式 S2 上位，拨轮在 **3 秒内上拨两次**，开始卸力。
4. 观察：`unload_step` 依次为 2 接住（快速到 MID）→ 3 慢速接住 → 4 开锁 → 5 送回，最后上膛回到 UP。
5. **重点看开锁那一刻**：电流峰值、`pos` 回退了多少、有没有异响或跳齿。把这些数据记进 CHANGELOG。

**完成标准**：连续 5 次卸力都成功；开锁时 `pos` 回退量小且稳定；没有误报故障。

**注意**
- 开锁瞬间电流会明显变大，这在预期之内。判断标准见 [状态机说明](状态机说明.md) 第 4 节。如果冲击过大，可以考虑让 `LOADER_POS_CATCH` 比 DOWN 略深一点，让拨弹板预先承担一部分力。
- 卸力过程中拨轮下拨可以随时停住，上膛原地保持。
- 如果卸力不可靠，**不要进入下一步**，先和机械一起解决。

### 步骤 16：单发流程空跑（不装镖）

**目的**：在没有镖的情况下，把整个单发流程完整走一遍，确认每一步的进入条件、完成条件和时序。

**操作**
1. 上电 → 自动找零 → 执行一次人工卸力，让储能状态变为"已释放"（上电后必须做这一步）。
2. S1 拨到**中位**（半自动），S2 上位，拨轮上拨：开始储能。
3. 在 MemRW3 中观察 `s_fsm.step`，应依次为：
   1 释放准备 → 3 下拉到 MID → 4 下拉到 DOWN → 5 锁止 → 6 回升 → 7 供弹（第 1 发为 0 步）→ 8 瞄准调力 → 9 待发。
4. 到"待发"时，蜂鸣器响 2 声，红灯快闪。
5. 拨轮再上拨：释放。`step` 依次为 10 释放中 → 11 复位 → 0 空闲，发序 +1。
6. 记录每一步的耗时，算出单发总时间。

**完成标准**：连续空跑 5 次都完整走完；单发总时间满足四发节拍要求（30 s 内打完四发，还要扣除开闸等待时间）。

**同时检查防呆**

| 检查 | 预期 |
|---|---|
| 储能过程中再拨轮上拨 | 没有反应（不会被记下来留到后面触发） |
| 到达"待发"之前拨轮上拨 | 不会释放 |
| 待发时拨轮下拨 | 中止；撒放器**不会**打开 |
| 中止后再拨轮上拨 | 从中止的地方继续 |
| 4 发打完后再启动 | 被拒，蜂鸣器一长一短 |

**注意**：被拒时查看 `s_fsm.last_start_deny`（启动被拒原因）或 `last_fire_deny`（释放被拒原因），位定义分别在 `dart_fsm.h` 和 `fire_gate.h` 中。

### 步骤 17：带镖单发

**目的**：第一次真正发射，确认出膛正常、机构承受得住冲击。

**操作**
1. 场地清场，射线方向安全，有缓冲或接镖网。
2. 人工放上第 1 枚镖，然后按步骤 16 执行。
3. 观察：出膛是否顺畅，飞镖有没有翻滚，释放后滑台的减速和冲击，撒放器舵机有没有被冲击打歪。
4. 检查：释放后再找零一次，零点是否偏移（判断冲击有没有导致同步带跳齿）。

**完成标准**：连续 5 发出膛正常；机构没有松动；零点没有偏移。

**注意**：变力目前还是位置控制。同一位置不代表同一拉力，也不代表同一初速，所以落点散布暂时只作参考。

### 步骤 18：异常与安全测试

**目的**：确认出现意外情况时，镖架的行为和设计一致。

**操作**（全部不装镖，每项测完都恢复到安全状态）

| 场景 | 操作 | 预期 |
|---|---|---|
| 下拉途中关控 | 单发进行到"下拉到 DOWN"时关掉遥控 | 上膛以低速受控回退到 UP，然后停止；不会猛地回弹 |
| 下拉途中拨到安全位 | 同上，改为 S1 拨到下位 | 同上 |
| 待发时关控 | 到"待发"后关掉遥控 | 锁扣是机械自锁，电机清零，滑台不动；重连后可以继续，也可以卸力 |
| 中止与恢复 | 储能各个阶段拨轮下拨，然后上拨 | 原地停住；恢复后从停下的地方继续 |
| 供弹中止 | 供弹过程中拨轮下拨 | S2 上位恢复会被拒；S2 下位上拨，跳过供弹继续 |
| 释放许可 | 待发时把 Yaw 推离目标（外力），再拨轮上拨 | 释放被拒（`last_fire_deny` 中 Yaw 位为 1），蜂鸣器一长一短 |
| 刚上电直接启动 | 上电找零后不卸力，直接到半自动拨轮上拨 | 被拒，原因是储能状态未知 |

**完成标准**：每一项都符合预期；不符合的项目记下来，修好之前不进入比赛使用。

**注意**：**不要用拔电机线、短路之类的破坏性方式测试故障。** 电机离线的处理逻辑（单侧保持、低速回退）可以在机构空载、低速时，由专人断开电调电源来测试。

## 阶段 I：打靶

### 步骤 19：每发参数标定

**目的**：确定第 1～4 发各自的 Yaw 瞄准角和变力位置。

**操作**
1. 先把 4 发都设为同一组参数（基地，Yaw 约 15.8°）。连续打若干发，记录落点、天气、电池电压。
2. 按落点偏差调整 `YAW_SHOT_DEG_TABLE`（左右）和 `TENSION_SHOT_POS_TABLE`（远近），一次只改一个量。
3. 手动模式 S2 下位，拨轮下拨：Yaw 和变力转到当前发序的预设位置，用来检查和对比。
4. 参数写回 `dart_config.h`，重新编译。

**完成标准**：同一组参数下的落点散布满足命中要求；每发参数都有对应的打靶记录。

**注意**
- 每发参数示教和 Flash 保存还没实现（计划和串口屏一起做），现在只能改宏、重新编译。
- 测力接入以后，变力会改成"锁止后按力微调"，这一步的参数要重新标定。

### 步骤 20：四发连续

**目的**：验证连续上膛和 30 s 四发的节拍。

**操作**
1. 4 发都放好（第 2～4 发需要供弹标定完成，即 `DART_FEEDER_CALIBRATED = 1`）。
2. 半自动模式 S2 中位，拨轮上拨：连续上膛。每发准备好后蜂鸣器响 2 声，切到 S2 上位、拨轮上拨发射。
3. 记录从第一次上拨到第四发出膛的总时间。

**完成标准**：四发完整打完，总时间满足要求，并留出余量。

**注意**：比赛用的 AUTO 模式（由裁判系统驱动）还没实现，现在的四发流程仍然需要人工逐发释放。

## 附：每次开机的日常流程（全部调好之后）

1. S1 拨到下位，打开遥控，给镖架上电，等蓝灯、绿灯亮。
2. S1 拨到上位：自动找零，等"嘀"一声。
3. 手动模式 S2 上位，拨轮 3 秒内上拨两次，执行人工卸力，确认储能状态。
4. S1 拨到中位，按需要单发或连续上膛。
5. 结束时：没有储能的话直接断电；有储能就先卸力，再断电。
