## 2. 零点与回转位

### 2.1 为什么找零后要回转

找到零点后，轴会自动往回转一段，停在 home 位。这样做有三点好处：

| 好处 | 说明 |
|---|---|
| 不长期顶着限位 | 找零靠撞限位（堵转）完成。如果停在原地，电机会一直出力顶着限位，导致发热和结构受力 |
| 给反向运动留余量 | 停在限位上时，朝限位方向没有任何空间；回转后两个方向都能动 |
| 起点固定 | 每次找零后都停在同一位置，后续动作的起点一致，便于复现 |

回转量要合适：
- 太小：可能还贴着限位，下次动作又会触发堵转判定。
- 太大：占用有效行程，变力可调范围或 Yaw 转角会变小。
- 上膛（拨弹板）的回转位**就是 UP 位**，也就是平时等待的位置。它要离滑台足够远，不能碰到滑台；但也不宜太远，否则每发都要多走空程、多花时间。

### 2.2 现在的实现

```
找零：独立速度环以固定转速顶向限位
  → 指令电流够大、转速够小，并持续 100 ms，判定为堵转
  → 堵转点记为零点(逻辑位置 0)
  → 自动移动到 home_pos(回转位)，然后保持
```

| 轴 | 回转位 / 中位的配置宏 | 当前占位值 | 状态 |
|---|---|---|---|
| 上膛（拨弹板） | `LOADER_POS_UP`（同时也是回转量） | 20000 count | **待确认** |
| 变力 | `TENSION_ZERO_BACKOFF` | 4786247 count（26 的值） | **待确认** |
| Yaw | `YAW_DEG_CENTER`（找零后回到正中间） | 9.0°（暂取设计行程 0～18° 的中点） | **待确认** |

- 单位：count 是电机转子编码器的累计计数，8192 count 等于转子转一圈。Yaw 的角度按 `YAW_COUNT_PER_DEG = 819.2 count/°` 换算；这个系数只按 2006 的 36:1 减速比计算，**没有计入外部传动，待确认**。
- 方向：回转方向固定为远离限位的一侧，不需要另外配置。
- Yaw 中位只决定"找零后停在哪里"，和**每发的瞄准角**（`YAW_SHOT_DEG_TABLE`）是两回事，互不影响。

### 2.3 预留的在线调整接口

| 接口 | 作用 |
|---|---|
| 轴对象的 RAM 字段 `home_pos` | 上电时从配置宏复制。用调试器改写后，**下一次找零**或调用 `Mech_Axis_Request_Home()` 时按新值回转。掉电后恢复为配置值 |
| `Mech_Axis_Request_Home(axis, now)` | 让轴回到 `home_pos` |
| 调参接口 `g_dart_tune` 的位置模式 | 直接让某根轴走到指定位置，用来试验回转位 |
| 轴对象的 RAM 字段 `pos_min` / `pos_max` | 软限位，同样在上电时从配置复制。行程不同时可以临时放宽（见第 3 节） |

对应变量：`s_loader_axis`（loader.c）、`s_tension_axis`（tension.c）、`s_yaw_axis`（yaw.c）。

### 2.4 实车测量回转量（变力、上膛）

1. 确认镖架无储能。S1 拨到上位，等自动找零完成（"嘀"一声）。
2. 用调试器打开对应轴对象，观察 `pos`（当前位置，相对零点）。
3. 用遥控点动，把机构移到你认为合适的回转位：
   - 变力：S2 中位，左摇杆上下；
   - 上膛：S2 上位，右摇杆上下。
4. 记下此时的 `pos`，作为候选回转量。
5. 验证：把候选值写进 `home_pos`，然后在手动模式 S2 上位**拨轮下拨一次**。注意三轴会一起重新找零。找零完成后会自动回转，观察是否停在预期位置、是否已离开限位。找零过程中再拨一次拨轮可以取消。
6. 确认后，把数值写回 `dart_config.h` 对应的宏（变力改 `TENSION_ZERO_BACKOFF`，上膛改 `LOADER_POS_UP`），重新编译。

> [!warning] 上膛的特殊情况
> `LOADER_POS_UP` 既是回转位，也被单发流程使用。修改后必须确认两点：
> - 撒放器锁止时，拨弹板在 UP 位不会碰到滑台；
> - 释放许可中"上膛在 UP 附近"的判断（`LOADER_FIRE_HOLD_ERR`）仍然合理。

### 2.5 实车测量 Yaw 中位

1. 同上，先完成找零。
2. 在手动模式 S2 中位，用右摇杆左右把 Yaw 转到机械正中，可以用卷尺或角度尺对准。
3. 记下 `s_yaw_axis.pos`，换算成角度：中位角 = pos ÷ 819.2。如果外部传动比确认后系数变了，按新系数换算。
4. 验证：把 `pos` 写进 `s_yaw_axis.home_pos`，重新找零，看是否停在正中间。
5. 确认后，把角度写回 `YAW_DEG_CENTER`，重新编译。
6. 检查软限位 `YAW_DEG_MIN` / `YAW_DEG_MAX`（当前 0.5° / 17.5°，**待确认**）。中位必须在这个范围内，否则找零后的回转会被拒绝。

## 3. 行程测量

### 3.1 方法：用调试器读出实际行程

- 三根轴对象里的 `pos` 就是"相对零点走了多少"，单位是转子编码器 count（8192 count = 转子转一圈）。
- 机构停稳后，用调试器读出 `pos`，填进第 5 节的记录表，再写进 `dart_config.h` 对应的宏，重新编译。

| 轴 | 变量（文件） | 说明 |
|---|---|---|
| 上膛 | `s_loader_axis.pos`（loader.c） | 以左电机 L 的编码器为准 |
| 变力 | `s_tension_axis.pos`（tension.c） | |
| Yaw | `s_yaw_axis.pos`（yaw.c） | 角度 = pos ÷ `YAW_COUNT_PER_DEG` |
| 辅助 | `s_rx[i].torque_current_raw`（dart_motor.c；i 为 0 L、1 R、2 变力、3 Yaw） | 实际电流，用来判断接触点 |

**测量前必须先放宽软限位。** 新镖架如果比原来长，不放宽就会被现在的上限挡住。

| 轴 | 当前配置上限 | 测量时临时改为 | 改哪个变量 |
|---|---|---|---|
| 上膛 | `LOADER_POS_MAX` = 1360000 | **待确认**，建议先 +20% | `s_loader_axis.pos_max` |
| 变力 | `TENSION_POS_MAX` = 9000000 | **待确认** | `s_tension_axis.pos_max` |
| Yaw | 17.5°，约 14336 count | **待确认** | `s_yaw_axis.pos_max` / `pos_min` |

> [!warning]
> 放宽软限位后就失去了软件保护，必须**低速、小步**地接近机械极限。测完断电重启，软限位即恢复原值。

### 3.2 需要测的点

**上膛（拨弹板）**

```
零点(堵转点) ─ UP(回转位) ────────── MID ─ 接触点 ─ DOWN(锁止位)/CATCH(接住位) ─ 机械极限
   0          LOADER_POS_UP       LOADER_POS_MID      LOADER_POS_DOWN / CATCH      ≥ LOADER_POS_MAX
```

| 点 | 含义 | 判断方法 | 写到哪 |
|---|---|---|---|
| ① UP（回转位） | 拨弹板等待的位置，必须离滑台足够远 | 撒放器锁住滑台时，拨弹板在这里不碰滑台，并留出余量 | `LOADER_POS_UP` |
| ② 接触点 | 拨弹板刚碰到滑台的位置 | 慢速向下，`torque_current_raw` 突然升高，或肉眼看到接触 | 只记录 |
| ③ MID | 快速段的终点 | 取**接触点之前**一段安全距离（距离**待确认**） | `LOADER_POS_MID` |
| ④ DOWN（锁止位） | 锁扣能可靠扣上的位置 | 撒放器打开，慢速向下拉到锁扣位置标记处，再稍多拉一点，确认留有余量 | `LOADER_POS_DOWN` |
| ⑤ CATCH（接住位） | 卸力时顶住已锁止滑台的位置 | 一般等于 DOWN，或比 DOWN 再多一点点，让锁扣卸载；**需要机械确认** | `LOADER_POS_CATCH` |
| ⑥ 机械极限 | 再往下就会顶死 | 慢速接近，电流明显升高、速度变为 0 | `LOADER_POS_MAX` = 极限 − 余量 |

**变力**

| 点 | 判断方法 | 写到哪 |
|---|---|---|
| 回转位 | 离开限位、便于调节的起点（见第 2.4 节） | `TENSION_ZERO_BACKOFF` |
| 最小 / 最大可用预紧位 | 先按机械刻度；接上测力后用力值标定 | `TENSION_POS_MAX`（最大值减余量） |
| 每发目标 | 先粗定，后续由测力或打靶结果修正 | `TENSION_SHOT_POS_TABLE` |

**Yaw**

| 点 | 判断方法 | 写到哪 |
|---|---|---|
| 中位 | 角度尺对准机械正中（见第 2.5 节） | `YAW_DEG_CENTER` |
| 左右可用极限 | 线束和结构不干涉的最大角度 | `YAW_DEG_MIN` / `YAW_DEG_MAX` |
| 基地瞄准角 | 打靶或视觉对准 | `YAW_SHOT_DEG_TABLE` |

**换算系数**（建议测一次并存档）
- **Yaw**：走一段已知的 count（例如 8192），用角度尺量出实际转角，算出 `YAW_COUNT_PER_DEG`。现在的 819.2 只算了 2006 自带的 36:1 减速，**没有计入外部传动，待确认**。
- **上膛、变力**：走一段已知的 count，量出滑台或丝杆实际移动的 mm，记下 count/mm。以后换算行程或排查打滑时会用到。

## 4. 测量步骤

### 4.1 准备（每次都做）

1. **撒放器打开、不装镖、对着缓冲或接镖网**，人员远离运动范围。
2. S1 拨到下位，上电；再拨到上位（手动），等自动找零完成，听到"嘀"一声。
3. 用 MemRW3 连接，加入以下变量：
   - Table：`s_loader_axis`、`s_tension_axis`、`s_yaw_axis` 三个结构体，以及 `g_dart_tune`；
   - Chart：`pos` 和 `torque_current_raw`。
4. 按第 3.1 节放宽对应轴的 `pos_max`。

### 4.2 用调参接口小步移动（推荐）

调参接口比摇杆点动更精确，也更可控：

1. 写 `g_dart_tune.axis`（0 上膛、1 变力、2 Yaw）和 `mode = 2`（位置模式），把 `pos_speed_limit` 设为**低速**（例如 300 rpm，**待确认**），最后写 `enable = 1`。
2. 把 `pos_target` 设为当前 `pos` 加一个小步长：上膛、变力先用 20000 count，Yaw 用 400 count（步长均**待确认**）。然后把 `seq` 加 1，等机构停稳。
3. 读取 `pos` 和电流，填入第 5 节的记录表。重复第 2 步，直到到达目标点。
4. 接近接触点或机械极限时，把步长缩小到 2000 count 或更小。
5. 测完写 `enable = 0`。

也可以用摇杆点动：手动模式 S2 上位用右摇杆（上膛），S2 中位用左摇杆（变力）、右摇杆（Yaw）。点动目标最多超前实际位置 `*_JOG_LEAD_MAX`，所以顶到障碍时会报堵转并停止，不会无限加力。

### 4.3 上膛测量的特别注意

- 拨弹板拉着滑台向下时，**拉簧就开始储能了，而且只靠电机拉着**。测完接触点以后的点，必须先**慢速送回 UP**，再做其他操作。
- 测锁止位 DOWN 时，如果锁扣扣上了，滑台就处于已储能状态。之后要按遥控器手册的**卸力流程**处理，不要直接打开撒放器。
- 测量途中如果拨到安全位，会触发受控回退：上膛会慢速自动送回 UP。

### 4.4 写回程序

1. 把记录表的结果写进 `dart_config.h` 对应的宏，注释改成"实测 日期"。
2. 检查各点的大小关系：0 < UP < MID < 接触点 ≤ DOWN ≤ CATCH < POS_MAX。
3. 重新编译，确认 `0 Error(s)`；再上机完整走一遍单发和卸力，确认无误。
4. 在 [CHANGELOG](../CHANGELOG.md) 中注明测量日期、镖架编号或版本、测量人。

### 4.5 测量后要同步检查的参数

| 参数 | 原因 |
|---|---|
| `LOADER_FIRE_HOLD_ERR` | UP 位变了，"上膛在 UP 附近"的判断范围也要跟着确认 |
| `LOADER_SPEED_FAST/SLOW`、`LOADER_SPEED_RETREAT` | 行程变长后，单发时间和回退时间都会变长（运动超时已按距离自动计算） |
| `*_HOLD_STALL_ERR`、`*_JOG_LEAD_MAX` | 卡死判定和点动超前量，要按实际负载确认 |
| 每发表 | Yaw 和变力的每发目标，要在新坐标下重新确认 |
