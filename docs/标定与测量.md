# 零点与中位调整说明（RP27_Dart V0.5）

> [!tip] 前置知识
> 先读 [遥控器手册.md](遥控器手册.md) 和 [调试工具配置.md](调试工具配置.md)。本文中所有回转量、中位数值都是**待确认**，需要实车测量。

## 1. 思路是否合理

**合理，而且现在的代码就是这样做的**：找到零点后，自动往回转一段，停在 home 位。

| 好处 | 说明 |
|---|---|
| 不长期顶着限位 | 找零是靠撞限位（堵转）完成的。如果停在原地，电机会一直出力顶着限位，导致发热、结构受力 |
| 给反向运动留余量 | 停在限位上时，向限位方向没有任何空间。回转后两个方向都能动 |
| 定一个固定的起点 | 每次找零后都停在同一个位置，后续动作的起点一致，方便复现 |

注意两点：
- 回转量太小：可能还贴着限位，下次动作会再次触发堵转判定。
- 回转量太大：占用有效行程，变力可调范围或 Yaw 的转角会变小。
- 上膛（拨弹板）的回转位**就是 UP 位**，也就是平时等待的位置。它要离滑台足够远，不碰到滑台；同时不宜太远，否则每发要多走空程、多花时间。

## 2. 现在的实现

```
找零：独立速度环以固定转速顶向限位
  → 指令电流够大、转速够小，并持续 100 ms，判定为堵转
  → 堵转点记为零点(逻辑位置 0)
  → 自动移动到 home_pos(回转位)，然后保持
```

| 轴 | 回转位 / 中位的配置宏（`dart_config.h`） | 当前占位值 | 状态 |
|---|---|---|---|
| 上膛（拨弹板） | `LOADER_POS_UP`（同时也是回转量） | 20000 count | **待确认** |
| 变力 | `TENSION_ZERO_BACKOFF` | 4786247 count（26 的值） | **待确认** |
| Yaw | `YAW_DEG_CENTER`（找零后回到正中间） | 9.0°（暂取设计行程 0～18° 的中点） | **待确认** |

- 单位：count 是电机转子编码器的累计计数，8192 count 等于转子转一圈。Yaw 的角度按 `YAW_COUNT_PER_DEG = 819.2 count/°` 换算；这个系数只按 2006 的 36:1 减速比计算，**没有计入外部传动，待确认**。
- 方向：回转方向固定为"远离限位的那一侧"，不需要另外配置。
- Yaw 中位只决定"找零后停在哪里"，和**每发的瞄准角**（`YAW_SHOT_DEG_TABLE`）是两回事，互不影响。

### 预留的接口

| 接口 | 作用 |
|---|---|
| 轴对象的 RAM 字段 `home_pos` | 上电时从配置宏复制过来。用调试器改写后，**下一次找零**或调用 `Mech_Axis_Request_Home()` 时就按新值回转。掉电后恢复为配置值 |
| `Mech_Axis_Request_Home(axis, now)` | 让轴回到 `home_pos` |
| 调参接口 `g_dart_tune` 的位置模式 | 直接让某根轴走到指定位置，用来试验回转位（见 PID 调试指南） |
| 轴对象的 RAM 字段 `pos_min` / `pos_max` | 软限位，同样在上电时从配置复制。新镖架行程不同时可以临时放宽，见[行程测量方案](行程测量方案.md) |

对应的变量：`s_loader_axis.home_pos`（loader.c）、`s_tension_axis.home_pos`（tension.c）、`s_yaw_axis.home_pos`（yaw.c）。

## 3. 实车测量回转量（变力、上膛）

1. 镖架处于无储能状态。S1 拨到上位，等自动找零完成（"嘀"一声）。
2. 用调试器打开对应轴对象，观察 `pos`（当前位置，相对零点）。
3. 用遥控点动，把机构移到你认为合适的回转位：
   - 变力：S2 中位，左摇杆上下；
   - 上膛：S2 上位，右摇杆上下。
4. 记下此时的 `pos`，作为候选回转量。
5. 验证：把候选值写进 `home_pos`，然后在手动模式 S2 上**拨轮下拨一次**。注意三轴会一起重新找零。找零完成后会自动回转，观察是否停在预期位置、是否离开了限位。找零过程中再拨一次拨轮会取消找零。
6. 确认后，把数值写回 `dart_config.h` 对应的宏（变力改 `TENSION_ZERO_BACKOFF`，上膛改 `LOADER_POS_UP`），重新编译。

> [!warning] 上膛的特殊情况
> 上膛的回转位就是 UP 位，`LOADER_POS_UP` 同时被单发流程使用。修改后必须确认两点：
> - 撒放器锁止时，拨弹板在 UP 位不会碰到滑台；
> - 释放许可中"上膛在 UP 附近"的判断（`LOADER_FIRE_HOLD_ERR`）仍然合理。

## 4. 实车测量 Yaw 中位

1. 同上，先完成找零。
2. 用右摇杆左右（手动模式 S2 中）把 Yaw 转到机械上的正中间，可以用卷尺或角度尺对准。
3. 记下 `s_yaw_axis.pos`，换算成角度：中位角 = pos ÷ 819.2（如果外部传动比确认后系数变了，按新系数换算）。
4. 验证：把 `pos` 值写进 `s_yaw_axis.home_pos`，重新找零，看是否停在正中间。
5. 确认后，把角度写回 `YAW_DEG_CENTER`，重新编译。
6. 检查软限位 `YAW_DEG_MIN` / `YAW_DEG_MAX`（当前 0.5° / 17.5°，**待确认**）：中位必须在这个范围内，否则找零后的回转会被拒绝。
