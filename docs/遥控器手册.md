# 遥控器操作手册（RP27_Dart V0.5）

> [!warning] 本手册尚未上机验证
> S1/S2 的左右、拨轮的上下方向都需要在实物上确认。

## 一、遥控器各部分说明

### 1. 开关和拨轮是干什么的

| 部件 | 通俗理解 | 怎么用 |
|---|---|---|
| **S1（左侧三档开关）** | **总开关和模式选择**：决定镖架处于"停着""调试""发射"中的哪一种 | 拨到上、中、下三个位置 |
| **S2（右侧三档开关）** | **功能选择**：在当前模式下，选择拨轮和摇杆控制哪一组功能 | 拨到上、中、下三个位置 |
| **拨轮** | **执行按钮**：拨一下就执行一次当前选中的功能 | 上拨或下拨。拨一下只算一次，要回中才能再拨，长按不会重复 |
| **右摇杆** | 手动模式下微调机构位置 | 推得越多动得越快，松手就停 |
| **左摇杆** | 手动模式下微调变力 | 同上 |

### 2. S1：选模式

| S1 | 模式 | 通俗说明 |
|---|---|---|
| **下** | **安全** | 所有电机停止，相当于"挂空挡"。开机后必须先在这里停一下；有故障时拨回这里清除 |
| **上** | **手动** | 调试用，可以单独动每个机构。和 2026 一样 |
| **中** | **半自动** | 发射用：拨一下储能，再拨一下发射 |

> [!tip] 两条规则
> - 开机或遥控重连后，**S1 必须先拨到下位一次**，否则遥控操作无效。
> - 开机后**第一次把 S1 拨离下位时，三轴会自动找零**（自动找到机械起点）。人要远离机构。

### 3. 手动模式（S1 上）各档位

| S2 | 摇杆 | 拨轮上 | 拨轮下 |
|---|---|---|---|
| **上：上膛与撒放器** | 右摇杆上下：上膛机构移动 | 撒放器 锁住/打开。如果机构可能已储能，要在 3 秒内拨两次，执行**卸力** | 开始找零；找零过程中再拨一次 = 取消 |
| **中：瞄准与变力** | 右摇杆左右：Yaw；左摇杆上下：变力 | 单独测试当前这一发的供弹动作 | 切换镖编号 1→2→3→4→1 |
| **下：供弹与预设** | — | 供弹舵机全部回到初始位 | Yaw 和变力转到当前这一发的预设位置 |

### 4. 半自动模式（S1 中）各档位

| S2 | 拨轮上 | 拨轮下 |
|---|---|---|
| **上：单发** | 第一次：**储能**（自动完成下拉、锁止、供弹、瞄准、调力）<br>听到"嘀嘀"后再拨一次：**发射** | 中止 |
| **中：连续** | 连续上膛：打完一发自动准备下一发，每发仍要手动发射 | 中止 |
| **下：补救** | 供弹中途被中止后，确认镖已手动放好，再继续 | 中止 |

### 5. 指示灯和蜂鸣器

| 信号 | 含义 |
|---|---|
| 蓝灯亮 | 遥控在线 |
| 绿灯常亮 / 闪 | 电机全部在线 / 正在找零 |
| 红灯常亮 | 有故障，S1 拨到下位清除 |
| **红灯快闪** | **已储能或待发，人不要站在射线方向** |
| 红灯慢闪 | 流程被中止，等待继续 |
| 嘀（1 声） | 找零完成 |
| 嘀嘀（2 声） | 待发，可以发射 |
| 嘀——嘀（一长一短） | 操作被拒，没有动作（条件不满足） |
| 嘀嘀嘀（3 声） | 出现故障 |

## 二、使用场景与操作步骤

### 1. 正常使用：开机到单发

1. S1 拨到**下位**，打开遥控，给镖架上电。等蓝灯、绿灯亮起。
2. S1 拨到**上位**（手动）：三轴自动找零。等"嘀"一声、绿灯常亮。
3. 开机后**先做一次卸力确认**：见下一节。机构确实没有储能时，这一步只是空走一遍，没有危害。
4. S1 拨到**中位**（半自动），S2 拨到**上位**，拨轮上拨：开始储能。
5. 听到"嘀嘀"、红灯快闪，表示待发。确认射线方向没有人。
6. 拨轮再上拨：**发射**。镖架自动回到可以打下一发的状态，镖编号 +1。
7. 打下一发：重复第 4～6 步。

### 2. 卸力（已经锁住、储能，但决定不打）

1. S1 拨到**上位**（手动），S2 拨到**上位**。
2. 如果刚开机还没找零，先拨轮下拨找零，等"嘀"一声。
3. **拨轮 3 秒内上拨两次**。机构依次执行：
   - 上膛下去顶住滑台；
   - 打开撒放器（拉簧的力由电机接住）；
   - 慢慢把滑台送回去。
4. 过程中拨轮下拨可以随时停住。停住后可以用右摇杆慢慢手动送回。
5. 上膛回到上方并停住，就表示完成（没有专门的提示音）。如果原来红灯在快闪，此时会停止。

> [!warning]
> 第一次测试卸力时**不要装镖**，并对着缓冲或接镖网。

### 3. 其他场景

| 场景 | 操作 |
|---|---|
| **储能途中想停下** | 拨轮下拨中止，机构原地停住。想继续就再拨轮上拨，从停下的地方接着来 |
| **连续打几发** | 半自动、S2 中位，拨轮上拨。每发准备好后会"嘀嘀"，再到 S2 上位拨轮上拨发射 |
| **下拉途中遥控断开或拨到安全位** | 上膛会自动慢速把滑台送回，然后停止。等它停稳再靠近 |
| **上膛一侧电机掉线**（红灯常亮、嘀嘀嘀） | 流程自动中止，另一侧电机原地顶住。尽快把 S1 拨到下位：上膛会低速单侧送回，然后停止。如果不操作，约 5 秒后也会自动送回 |
| **已锁住时遥控断开** | 安全，锁扣是机械锁死的。重连后 S1 先拨下位一次，再选择继续打或卸力 |
| **拨轮上拨没反应，听到"嘀——嘀"** | 条件不满足。常见原因：还没找零、开机后还没卸力、有故障、4 发已打完、第 2～4 发的供弹参数还没标定 |
| **红灯常亮（有故障）** | S1 拨到下位清除。如果是电机掉线，要先查线；电机重新上线后需要重新找零（手动 S2 上、拨轮下拨） |
| **4 发打完想重来** | 手动模式、S2 中位，拨轮下拨，把镖编号切回 1 |
| **单独测试供弹** | 手动模式、S2 中位，先用拨轮下拨选好镖编号，再拨轮上拨执行 |
| **检查预设瞄准位置** | 手动模式、S2 下位，拨轮下拨：Yaw 和变力转到当前镖编号的预设位置 |
| **调 PID** | 用调试器操作，见 `PID调试指南.md`。调试期间遥控摇杆无效，拨轮下拨立即退出 |

## 三、操作前注意

- 找零、储能、卸力、发射都会使机构动作，操作前确认人员已离开运动区域和射线方向。
- S1 从下位拨到上位时，会短暂经过中位（半自动）。只要不拨拨轮，就不会有任何动作。
- 完整的启动条件和状态说明见 [README](Readme.md)。
