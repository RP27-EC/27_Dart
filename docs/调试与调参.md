# 调试工具配置（Ozone / MemRW3）

> [!tip] 前置知识
> - 工程的调试探针是 **J-Link**：Keil 工程使用的调试驱动是 `Segger\JL2CM3.dll`。
> - 本机已安装 SEGGER Ozone 和 J-Link V9.76，路径为 `C:\Program Files\SEGGER\`。
> - 固件调试文件：`G:\STM32_ALL\RM\code\RP27_Dart\MDK-ARM\My_C\My_C.axf`。Keil 工程已经开启调试信息，**每次重新编译后都要在工具里重新加载**。
> - 我没法替你操作图形界面，下面写成可以照着做的清单。凡是界面上的叫法可能因版本不同的地方，都标了"待确认"。

## 0. 共同注意事项

| 事项 | 说明 |
|---|---|
| **同一时间只能有一个工具连接探针** | Keil 调试、Ozone、MemRW3 三者只开一个，否则会连接失败 |
| **不要暂停 CPU** | 镖架运动或储能时，不要按暂停、不要打断点、不要单步。CPU 暂停后控制循环停止，CAN 不再发送新指令；电调此时是停止输出还是保持最后一次指令，**待确认**（与电调型号的掉线保护有关）。下拉途中暂停可能导致滑台回弹 |
| **不要用工具烧录或复位** | 只做观察和写变量。烧录用 Keil。复位会让零点和储能状态丢失 |
| **写变量只改 RAM** | 掉电后恢复原值。调好的值要写回 `dart_config.h` 并重新编译 |
| **静态变量** | 轴对象等变量是文件内的 `static`，在工具里可能显示为 `loader.c` 下的 `s_loader_axis`，或带有文件作用域前缀。按名字搜索即可 |
| **枚举显示为数字** | 数字和含义的对照见本文第 3 节 |

## 1. Ozone 配置清单

### 1.1 新建工程（File → New → New Project Wizard）

| 步骤 | 参数 | 填写 / 推荐值 |
|---|---|---|
| Device | Device | `STM32F407IG`（ST 厂商下面选） |
| | Peripherals（SVD 文件） | `G:\Keil 5\Pack\Keil\STM32F4xx_DFP\2.17.1\CMSIS\SVD\STM32F407.svd` |
| Connection | Target Interface | **SWD** |
| | Target Interface Speed | **4 MHz**；不稳定时降到 1 MHz |
| | Host Interface | USB（只插了一个 J-Link 时不用选序列号） |
| Program File | Program file | `G:\STM32_ALL\RM\code\RP27_Dart\MDK-ARM\My_C\My_C.axf` |
| Optional | Initial PC / Stack Pointer | 保持默认值（从映像读取） |

完成后，用 File → Save Project as 保存成 `MDK-ARM\RP27_Dart.jdebug`，下次直接打开即可。

### 1.2 连接方式：用 Attach，不要用下载

- 菜单 Debug → **Attach to Running Program**（具体名称**待确认**，Ozone 版本不同可能叫 "Attach & Halt" / "Attach & Continue"，要选**不暂停**的那个）。
- **不要**使用 "Download & Reset Program"：它会重新烧录并复位。

### 1.3 观察变量和画曲线

| 窗口 | 用法 |
|---|---|
| **Watched Data**（View → Watched Data） | 右键 → Add，输入表达式，例如 `s_yaw_axis.pos`、`g_dart_tune`。在属性里把刷新设为**实时刷新**（选项名**待确认**，一般叫 Live Watch 或 Refresh rate），可以在 CPU 运行时持续刷新 |
| 修改变量 | 在 Watched Data 里双击 Value 列，输入新值后回车。J-Link 支持在 CPU 运行时写内存 |
| **Data Sampling**（View → Data Sampling） | 加入要画曲线的表达式，采样频率建议 1 kHz（能达到多少取决于 SWD 速度和变量个数，**待确认**） |
| **Timeline** | 和 Data Sampling 配合使用，显示曲线。可以缩放、对比多条曲线 |
| Peripherals | 已加载 SVD 时，可以查看 TIM1、CAN 等寄存器 |

### 1.4 推荐的观察组合

- **调 Yaw 内环**：`s_yaw_axis.tune_speed`、`s_yaw_axis.speed`、`s_yaw_axis.output`
- **调 Yaw 外环**：`s_yaw_axis.target`、`s_yaw_axis.pos`、`s_yaw_axis.pos_pid.out`、`s_yaw_axis.status`
- **调参控制**：`g_dart_tune`（展开后逐个字段写入）
- **全局状态**：`s_fsm.mode`、`s_fsm.step`、`s_fsm.energy`、`s_fault_mask`

## 2. MemRW3 配置清单

工具路径：`F:\download\调试工具\MemRW3\MemRW3.exe`，桌面快捷方式 `MemRW3.lnk` 指向它。它基于 probe-rs，支持 J-Link。完整说明在同目录的 `使用说明.md`。

### 2.1 连接

| 步骤 | 参数 | 填写 / 推荐值 |
|---|---|---|
| 设置 → MCU 型号 | 芯片 | `STM32F407IGHx`（以列表中的实际写法为准，**待确认**） |
| 设置 → 协议 | 接口 | **SWD** |
| 设置 → 探针 | 探针 | 列表里的 J-Link（确认已关闭 Keil 和 Ozone） |
| 设置 → 速度 | 速度 | 4000 kHz；连接不稳定时降到 1000 kHz |
| 连接 | — | 点击"连接"，状态变为已连接。**连接只建立通道，不会开始采集** |
| 开始 | — | 点击全局"开始"后才开始读数据 |

### 2.2 加载变量

1. Chart 或 Table 中点击"打开变量树"，选择 `My_C.axf` 并点击"加载"。
2. 在树里搜索变量名，例如 `s_yaw_axis`，展开结构体。
3. 想画曲线的标量：选中后填写曲线名和颜色，点击"添加到 Chart"。
4. 想看数值或修改的变量：选中后点击"添加到 Table"。结构体可以整个加进去，例如 `g_dart_tune`、`s_yaw_axis.spd_pid`。
5. 修改：在 Table 的写入框里输入新值，回车提交。浮点数直接输入小数。

### 2.3 采样与记录

| 设置 | 推荐值 | 说明 |
|---|---|---|
| 控制栏中的延迟 | 0 | 尽可能快地采样 |
| 曲线数量 | 每次 3～4 条 | 变量越多，采样越慢 |
| 保留全部采样 | 开启（默认） | 内存会随时间增长，长时间记录时要分段 |
| CSV 路径 | 每次开始前换一个新文件名 | **再次点击"开始"会覆盖同一个 CSV**，例如按 `yaw_spd_01.csv`、`yaw_spd_02.csv` 依次命名 |
| Table 刷新频率 | 10～20 Hz | 只影响表格显示，不影响曲线采样 |

### 2.4 注意事项

- **不要点击"烧录固件"**，烧录用 Keil。
- 重新编译后：先停止采集，重新加载 AXF，再用"追踪"更新变量地址。
- Debug 面板的"暂停"会暂停 MCU，**镖架运动时不要用**。
- 配置可以保存成 JSON，下次直接加载。加载前要先停止采集并断开连接。

## 3. 枚举数值对照

| 变量 | 数值含义 |
|---|---|
| `s_fsm.mode` | 0 安全，1 手动，2 半自动，3 自动（预留） |
| `s_fsm.step` | 0 空闲，1 释放准备，2 下拉前供弹，3 下拉到 MID，4 下拉到 DOWN，5 锁止，6 回升，7 供弹，8 瞄准调力，9 待发，10 释放中，11 复位，12 已中止 |
| `s_fsm.energy` | 0 未知，1 已释放，2 已储能 |
| `s_fsm.unload_step` | 0 无，1 降预紧，2 接住（快速到 MID），3 慢速接住，4 开锁，5 送回 |
| `s_*_axis.pos_min` / `pos_max` / `home_pos` | 软限位和回转位，RAM 中可在线修改，测量行程时使用 |
| `s_*_axis.status` | 0 无输出，1 找零中，2 保持，3 运动中，4 到位，5 调参速度模式，6 故障 |
| `s_*_axis.err` | 0 无，1 找零超时，2 运动超时，3 堵转，4 电机离线 |
| `s_trigger_state`（trigger.c） | 0 锁止中，1 已锁止，2 释放中，3 已释放 |
| `g_dart_tune.deny` | 位 1 不在手动，2 轴非法，4 未找零，8 可能储能，16 轴拒绝请求 |
| `s_fault_mask`（按位） | bit0 遥控离线，bit1 上膛 L 离线，bit2 上膛 R 离线，bit3 变力离线，bit4 Yaw 离线，bit5 上膛轴故障，bit6 变力轴故障，bit7 Yaw 轴故障，bit8 单发超时，bit9 请求被拒 |

## 4. 选哪个工具

| 需求 | 推荐 |
|---|---|
| 调 PID：边改参数边看曲线 | **MemRW3**：表格写值加曲线最直接，能导出 CSV |
| 看寄存器、需要断点（只在机构静止、无储能时） | **Ozone** |
