# 调试与调参工具（Ozone / MemRW3）

> [!tip] 前置知识
> - 本工程的调试探针是 **J-Link**，Keil 工程使用的调试驱动是 `Segger\JL2CM3.dll`。
> - 本机已安装 SEGGER Ozone 和 J-Link V9.76，路径为 `C:\Program Files\SEGGER\`。
> - 固件调试文件：`G:\STM32_ALL\RM\code\RP27_Dart\MDK-ARM\My_C\My_C.axf`。Keil 工程已开启调试信息，**每次重新编译后都要在工具里重新加载**。
> - PID 怎么调见 [PID 调试指南](PID调试指南.md)；行程和零点怎么测见 [标定与测量](标定与测量.md)。

本文合并了原《调试工具配置》和《MemRW3 调参配置使用说明》。

## 0. 共同注意事项

| 事项 | 说明 |
|---|---|
| **同一时间只能有一个工具连接探针** | Keil 调试、Ozone、MemRW3 三者只能开一个，否则会连接失败 |
| **不要暂停 CPU** | 镖架运动或储能时，不要按暂停、打断点或单步。CPU 暂停后控制循环停止，CAN 不再发送新指令；电调这时是停止输出还是保持最后一次指令，**待确认**（取决于电调型号的掉线保护）。下拉途中暂停可能导致滑台回弹 |
| **不要用工具烧录或复位** | 只做观察和写变量，烧录用 Keil。复位会让零点和储能状态丢失 |
| **写变量只改 RAM** | 掉电后恢复原值。调好的值要写回 `dart_config.h` 并重新编译 |
| **静态变量** | 轴对象等变量是文件内的 `static`，工具里可能显示为 `loader.c` 下的 `s_loader_axis`，或带有文件作用域前缀。按名字搜索即可 |
| **枚举显示为数字** | 数字与含义的对照见第 3 节 |

## 1. Ozone 配置

### 1.1 新建工程（File → New → New Project Wizard）

| 步骤 | 参数 | 填写 / 推荐值 |
|---|---|---|
| Device | Device | `STM32F407IG`（在 ST 厂商下选） |
| | Peripherals（SVD 文件） | `G:\Keil 5\Pack\Keil\STM32F4xx_DFP\2.17.1\CMSIS\SVD\STM32F407.svd` |
| Connection | Target Interface | **SWD** |
| | Target Interface Speed | **4 MHz**；不稳定时降到 1 MHz |
| | Host Interface | USB（只插一个 J-Link 时不用选序列号） |
| Program File | Program file | `G:\STM32_ALL\RM\code\RP27_Dart\MDK-ARM\My_C\My_C.axf` |
| Optional | Initial PC / Stack Pointer | 保持默认（从映像读取） |

完成后用 File → Save Project as 保存为 `MDK-ARM\RP27_Dart.jdebug`，下次直接打开即可。

### 1.2 连接方式：用 Attach，不要用下载

- 菜单 Debug → **Attach to Running Program**。具体名称**待确认**：不同版本的 Ozone 可能叫 "Attach & Halt" 或 "Attach & Continue"，要选**不暂停**的那个。
- **不要**用 "Download & Reset Program"，它会重新烧录并复位。

### 1.3 观察变量和画曲线

| 窗口 | 用法 |
|---|---|
| **Watched Data**（View → Watched Data） | 右键 → Add，输入表达式，例如 `s_yaw_axis.pos`、`g_dart_tune`。在属性里把刷新方式设为**实时刷新**（选项名**待确认**，一般叫 Live Watch 或 Refresh rate），CPU 运行时也能持续刷新 |
| 修改变量 | 在 Watched Data 里双击 Value 列，输入新值后回车。J-Link 支持在 CPU 运行时写内存 |
| **Data Sampling**（View → Data Sampling） | 加入要画曲线的表达式，采样频率建议 1 kHz（实际能达到多少取决于 SWD 速度和变量个数，**待确认**） |
| **Timeline** | 与 Data Sampling 配合，显示曲线，可以缩放、对比多条曲线 |
| Peripherals | 加载 SVD 后，可以查看 TIM1、CAN 等寄存器 |

### 1.4 推荐的观察组合

- **调 Yaw 内环**：`s_yaw_axis.tune_speed`、`s_yaw_axis.speed`、`s_yaw_axis.output`
- **调 Yaw 外环**：`s_yaw_axis.target`、`s_yaw_axis.pos`、`s_yaw_axis.pos_pid.out`、`s_yaw_axis.status`
- **调参控制**：`g_dart_tune`（展开后逐个字段写入）
- **全局状态**：`s_fsm.mode`、`s_fsm.step`、`s_fsm.energy`、`s_fault_mask`

## 2. MemRW3 配置

工具路径：`F:\download\调试工具\MemRW3\MemRW3.exe`，桌面快捷方式 `MemRW3.lnk` 指向它。它基于 probe-rs，支持 J-Link。完整说明在工具同目录的 `使用说明.md`。

### 2.1 连接

| 步骤 | 参数 | 填写 / 推荐值 |
|---|---|---|
| 设置 → MCU 型号 | 芯片 | `STM32F407IGHx`（以列表中的实际写法为准，**待确认**） |
| 设置 → 协议 | 接口 | **SWD** |
| 设置 → 探针 | 探针 | 列表里的 J-Link（先确认已关闭 Keil 和 Ozone） |
| 设置 → 速度 | 速度 | 4000 kHz；连接不稳定时降到 1000 kHz |
| 连接 | — | 点击"连接"，状态变为已连接。**连接只建立通道，不会开始采集** |
| 开始 | — | 点击全局"开始"后才开始读数据 |

### 2.2 现成调参配置（2026-11-03 生成）

配置文件放在工程根目录（工具加载时按此路径查找，所以没有移动）：

| 配置文件 | 默认曲线对象 | 需手动设置的 `g_dart_tune.axis` |
|---|---|---|
| [memrw3_config.json](../memrw3_config.json) | Yaw | 2 |
| [MemRW3_变力调参.json](../MemRW3_变力调参.json) | 变力 | 1 |
| [MemRW3_上膛调参.json](../MemRW3_上膛调参.json) | 上膛（左电机闭环、右电机镜像） | 0 |

- 三份配置都包含完整的三轴参数，共 132 个参数/观察项，按调参控制、整机状态、Yaw、变力、上膛分组；区别只是默认采集哪根轴、画哪些曲线，其他轴可以按需勾选。
- 字段显示名的格式为"原字段名 ｜ 中文说明"，原始变量路径保留，用于"追踪"。中文里写的"只读"只是操作提示，不是软件写保护。
- 默认显示目标转速和实际转速；电流指令与位置曲线已经加入，但默认隐藏，需要时再打开。不同单位的曲线画在一起会影响观察尺度。
- 原始空配置备份：`memrw3_config.json.bak`。

**加载步骤**
1. 先停止采集并断开目标，再在 MemRW3 中点击"加载配置"，选择上面某一份文件。
2. 芯片、SWD、1000 kHz 等设置沿用你保存过的配置。加载配置不会自动连接、复位或写变量，也**不会自动写入 `g_dart_tune.axis`**。
3. 确认板上固件和配置对应的是同一版 AXF，再由操作手连接并开始采集。
4. 变量地址绑定的是生成配置时的那一版 AXF。**每次重新编译后**都要先停止采集，重新加载新 AXF，再用"追踪"更新地址并核对，不能直接沿用旧地址。

### 2.3 手动加载变量

1. 在 Chart 或 Table 中点击"打开变量树"，选择 `My_C.axf` 并点击"加载"。
2. 在树里搜索变量名，例如 `s_yaw_axis`，展开结构体。
3. 想画曲线的标量：选中后填写曲线名和颜色，点击"添加到 Chart"。
4. 想看数值或修改的变量：选中后点击"添加到 Table"。结构体可以整个加入，例如 `g_dart_tune`、`s_yaw_axis.spd_pid`。
5. 修改变量：在 Table 的写入框里输入新值，回车提交。浮点数直接输入小数。

### 2.4 调参操作顺序（概要）

具体调法见 [PID 调试指南](PID调试指南.md)，这里只列操作顺序：

1. 先完成找零，S1 拨到上位进入手动模式，保持 `g_dart_tune.enable = 0`。
2. 设定 `axis`（0 上膛、1 变力、2 Yaw），选择 `mode`（0 关闭、1 速度、2 位置）。
3. 速度内环：先填 `speed_rpm`，再把 `enable` 写为 1；调整所选轴的 `spd_pid.kp/ki/kd/integral_max`，对比目标转速和实际转速。
4. 位置外环：先填 `pos_target` 和 `pos_speed_limit`，启用位置模式；之后每改变一次 `seq`（例如 0 改成 1）发起一次运动。调整所选轴的 `pos_pid`。
5. 调上膛时，要求软件推定的储能状态为"已释放"，且不在卸力过程中。所有调参动作仍受固件的模式、找零、故障和软限位约束。
6. 退出：把 `enable` 写为 0，或拨轮下拨；离开手动模式也会自动退出。RAM 中的参数在复位后恢复为配置值，调好后要回写源码。参数示教与 Flash 保存尚未实现。

### 2.5 采样与记录

| 设置 | 推荐值 | 说明 |
|---|---|---|
| 控制栏中的延迟 | 0 | 尽可能快地采样 |
| 曲线数量 | 每次 3～4 条 | 变量越多，采样越慢 |
| 保留全部采样 | 开启（默认） | 内存会随时间增长，长时间记录时要分段 |
| CSV 路径 | 每次开始前换一个新文件名 | **再次点击"开始"会覆盖同一个 CSV**，可按 `yaw_spd_01.csv`、`yaw_spd_02.csv` 依次命名 |
| Table 刷新频率 | 10～20 Hz | 只影响表格显示，不影响曲线采样 |

### 2.6 注意事项

- **不要点击"烧录固件"**，烧录用 Keil。
- Debug 面板的"暂停"会暂停 MCU，**镖架运动时不要用**。
- 配置可以另存为 JSON，下次直接加载；加载前先停止采集并断开连接。

### 2.7 配置验证情况

- JSON 格式与软件保存的空配置一致；Table/Chart 字段已对照软件源码核对过；变量地址、宽度和类型直接取自 AXF，不是按结构体手工计算的。
- 生成配置时桌面控制工具初始化失败，没有在本机界面里完成加载验证，需要在 MemRW3 中实际加载确认。没有做过任何硬件读写、暂停、复位或烧录。
- 生成配置时使用的 AXF，SHA-256 为 `6f6a3c69e2f05cf52806d39120469004d263e8a3188d466347336192ac0ee555`。之后重新编译过的 AXF 与它不同，需要按第 2.2 节更新地址。

## 3. 变量含义与枚举对照

**单位**
- 位置：电机转子累计编码器计数 count，8192 count/转。Yaw 的 count 不是角度，换算以 `YAW_COUNT_PER_DEG` 为准，外部传动待标定。
- 速度：转子 rpm，方向为逻辑方向。
- 输出：电调电流指令 raw，不是安培。

**几个容易混淆的字段**
- `home_pos` 是找零后的回转位，`pos_min` / `pos_max` 是 RAM 中的软限位。它们都不是四发预设表；不要去写 `cfg` 指针或 Flash 配置。
- PID 的 `integral_max` 限制积分累加量；`out_max` 等运行字段会被固件重写，不能当作持久的调参入口。

**枚举**

| 变量 | 数值含义 |
|---|---|
| `s_fsm.mode` | 0 安全，1 手动，2 半自动，3 自动（预留） |
| `s_fsm.step` | 0 空闲，1 释放准备，2 下拉前供弹，3 下拉到 MID，4 下拉到 DOWN，5 锁止，6 回升，7 供弹，8 瞄准调力，9 待发，10 释放中，11 复位，12 已中止 |
| `s_fsm.energy` | 0 未知，1 已释放，2 已储能 |
| `s_fsm.unload_step` | 0 无，1 降预紧，2 接住（快速到 MID），3 慢速接住，4 开锁，5 送回 |
| `s_*_axis.status` | 0 无输出，1 找零中，2 保持，3 运动中，4 到位，5 调参速度模式，6 故障 |
| `s_*_axis.err` | 0 无，1 找零超时，2 运动超时，3 堵转，4 电机离线 |
| `s_trigger_state`（trigger.c） | 0 锁止中，1 已锁止，2 释放中，3 已释放 |
| `g_dart_tune.deny` | 位 1 不在手动，2 轴非法，4 未找零，8 可能储能，16 轴拒绝请求 |
| `s_fault_mask`（按位） | bit0 遥控离线，bit1 上膛 L 离线，bit2 上膛 R 离线，bit3 变力离线，bit4 Yaw 离线，bit5 上膛轴故障，bit6 变力轴故障，bit7 Yaw 轴故障，bit8 单发超时，bit9 请求被拒 |

## 4. 选哪个工具

| 需求 | 推荐 |
|---|---|
| 调 PID：边改参数边看曲线 | **MemRW3**：表格写值加曲线最直接，能导出 CSV |
| 看寄存器、需要断点（只在机构静止、无储能时） | **Ozone** |
